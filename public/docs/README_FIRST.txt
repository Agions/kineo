           Kineo (Kineo AI) 漫剧创作平台 - 安装与初次使用必读说明
================================================================================

感谢您安装并使用 Kineo AI 漫剧创作平台！
本软件专为动漫创作者、网络小说改编团队及独立制作人打造，支持将纯文本小说与剧本
一键全自动转化为带角色一致性、运镜动态与多音轨配音的 4K 漫剧视频。

--------------------------------------------------------------------------------
【一、快速开始 (Quick Start)】
--------------------------------------------------------------------------------
1. 启动软件：
   - macOS: 双击打开 Applications 中的 Kineo.app。
   - Windows: 双击桌面快捷方式或开始菜单中的 Kineo。
   - Linux: 执行 kineo 启动命令。

2. 首次运行配置：
   - 点击界面左下角【设置 (Settings)】。
   - 配置至少一个可用大模型供应商的 API Key：
     * 国内推荐：DeepSeek (深度求索) / 百度千帆 (文心一言) / 阿里百炼 (通义千问)
     * 国际推荐：Google Gemini (Gemini 2.0 Flash) / OpenAI (GPT-4o) / Claude 3.7
     * 本地部署：OpenAI 兼容端点 (支持 Ollama / LocalAI / vLLM)
   - 音频 TTS 说明：软件已内置微软 EdgeTTS 免费高速音色（云希/晓晓等），无需
     额外购买或配置 TTS Key 即可直接生成对白语音。

3. 开启首个项目：
   - 点击首页【新建工程】按钮。
   - 输入工程名称（如《我的首部漫剧》），可直接点击【导入示范剧本】体验全流程。
   - 依次体验 9 步标准管线：策划导入 -> 故事洞察 -> 镜头切分 -> 分镜大盘 -> 
     角色锁脸 -> 场景渲染 -> 运镜合成 -> 音频工程 -> 4K 压制导出。

--------------------------------------------------------------------------------
【二、常用快捷键】
--------------------------------------------------------------------------------
- Cmd/Ctrl + N       : 新建漫剧工程
- Cmd/Ctrl + S       : 保存当前进度
- Space (空格键)     : 视频预览 播放 / 暂停
- Cmd/Ctrl + Enter   : 立即触发 AI 生成 / 渲染当前镜头
- J / K / L          : 倒放 / 暂停 / 快进
- Cmd/Ctrl + /       : 快速调起内置帮助中心文档

--------------------------------------------------------------------------------
【三、硬件加速建议】
--------------------------------------------------------------------------------
- macOS: 原生支持 Apple Silicon (M1/M2/M3/M4) 系列芯片 Metal 硬件编码。
- Windows: 推荐搭配 NVIDIA 独立显卡（GTX 1060 或 RTX 20/30/40/50 系列），
  视频压制与导出时将自动调用 NVENC 硬件芯片加速，渲染速度提升 3-5 倍。
