# 🚀 Kineo (Kineo AI) 快速上手指南

欢迎使用 **Kineo (Kineo AI) 漫剧创作平台**！
Kineo 是一款面向内容创作者、编剧、独立动画师及自媒体工作者的全流程 AI 漫剧视频生成器。它采用 **Tauri v2 + React 19 + Rust + Monorepo** 模块化微内核架构，能够将纯文本小说或分镜剧本，通过流水线引擎一键转化为具备镜头语言、角色一致性、多音轨 TTS 配音以及 4K 规格的专业漫剧视频。

## 1. 系统要求与硬件加速

| 平台 | 最低配置 | 推荐配置 | 硬件加速支持 |
| :--- | :--- | :--- | :--- |

## 2. 首次启动与模型配置

Kineo 支持主流大模型供应商直连，亦支持本地部署模型（如 Ollama / vLLM / LocalAI）。首次使用前，建议先前往 **【设置 (Settings)】** 配置至少一个 LLM 供应商以及图像生成服务：

### 2.1 支持的模型供应商与功能映射
1. **文本分析与分镜拆解 (LLM)**：
   - **Google Gemini**（推荐：`gemini-2.0-flash` / `gemini-1.5-pro`，支持超长上下文文本拆解）
   - **OpenAI**（`gpt-4o` / `gpt-4o-mini`）
   - **Anthropic Claude**（`claude-3-7-sonnet` / `claude-3-5-haiku`）
   - **DeepSeek**（`deepseek-chat` / `deepseek-reasoner`）
   - **百度千帆**（`ERNIE-4.0`）与 **阿里云百炼**（`qwen-max` / `qwen-plus`）
   - **OpenAI 兼容端点**（可填入 OneAPI / NewAPI / 本地 Ollama 代理）
2. **场景画面生成 (Text-to-Image)**：
   - 默认内置 **Seedream 5.0** 动漫引擎
   - 支持主流图像 API（Flux, Midjourney API, SDXL, Kling 图像生成）
3. **语音合成与音效 (TTS)**：
   - 微软 EdgeTTS（内置免费，无需配置 API Key，支持云希/晓晓等自然人声）
   - 阿里 CosyVoice / 百度语音 / 自定义克隆人声音色库

## 3. 漫剧创作 9 步标准管线

在首页点击 **【新建工程】** 后，进入项目编辑工作流，按照以下 9 步标准管线逐步推进：

```
[1. 策划与导入] ──> [2. 故事洞察] ──> [3. 分镜切分] ──> [4. 分镜大盘] ──> [5. 角色锁定]
                                                                          │
[9. 压制与导出] <── [8. 声音后期] <── [7. 镜头动效] <── [6. 画面渲染] <──┘
```

1. **Step 1: 策划与剧本导入**
   - 粘贴网络小说章节、剧本或大纲；支持一键载入《斗破苍穹》等经典示范模版。
2. **Step 2: 故事与情绪弧线分析**
   - AI 自动提炼核心人物、情绪起伏走势（起承转合）与高潮节奏点。
3. **Step 3: 极客分镜镜头拆分**
   - 将文本拆解为镜头单元，指定特写 (Close-up)、中景 (Medium Shot)、远景 (Wide Shot) 以及俯拍/仰拍机位。
4. **Step 4: 分镜大盘与视觉风格锁定**
   - 选择视觉基调（国漫修仙、赛博朋克、日系动漫、美漫暗黑风格），自动合成标准 Prompt。
5. **Step 5: 角色一致性锁定与 LoRA 档案库**
   - 锚定核心角色形象、发型发色、服饰装束与固定 Seed，确保整部漫剧多机位不“崩脸”。
6. **Step 6: 硬件加速场景渲染中心**
   - 批量提交 GPU/云端生成队列，实时查看画面生成质量与一致性校验评分。
7. **Step 7: 镜头动效与运镜轨迹合成**
   - 为静态画面赋予动态生命，配置推镜头 (Zoom-In)、拉镜头 (Zoom-Out)、横摇 (Pan) 与运镜关键帧。
8. **Step 8: 多音轨 TTS 配音与音频工程**
   - 智能识别台词对白，自动绑定专属配音员；添加环境 BGM 音轨与打击音效，生成音画同步波形。
9. **Step 9: 4K 压制、字幕同轴与多端发布**
   - 选择发布规格（16:9 横屏 B站/YouTube 4K 60fps、9:16 竖屏 抖音/TikTok 规格），一键导出压制成品！

## 4. Multi-Agent 多智能体协同工坊

在左侧导航栏选择 **【Agent 协同工坊】**，可体验全新升级的 **多智能体自治漫剧创作模式**：
- **🎬 总导演 Agent (Master Director)**：全局总览剧情节奏与进度质量门禁。
- **✍️ 编剧 Agent (Writer Agent)**：负责小说大纲拆解、台词精修与伏笔铺设。
- **🎨 分镜师 Agent (Storyboarder)**：输出构图预设、机位焦距与景深提示词。
- **⚙️ 制作师 Agent (Animator)**：负责图像生成批处理、运镜插帧与音轨同轴混音。
- **🛡️ 审核员 Agent (Quality Auditor)**：负责画质防畸变检测、角色一致性校验与打回重修。

## 5. 键盘快捷键与高效操作技巧

| 快捷键 (macOS / Windows) | 功能说明 | 适用页面 |
| :--- | :--- | :--- |
| `Cmd/Ctrl + N` | 新建漫剧工程 | 全局 |
| `Cmd/Ctrl + S` | 快速保存当前工程进度 | 编辑器各步骤 |
| `Space (空格键)` | 视频预览播放 / 暂停切换 | 分镜大盘、视频剪辑页 |
| `Cmd/Ctrl + Enter` | 立即触发当前步骤 AI 生成 / 渲染 | 剧本拆解、分镜渲染 |

| `[` / `]` | 选中上一个分镜 / 下一个分镜 | 分镜工作台 |
| `Cmd/Ctrl + /` | 打开 / 关闭内置帮助中心 | 全局 |

## 6. 常见故障排查 (FAQ)

### Q1: 软件无法连接 AI 模型，提示网络错误或超时？
- **排查**：请前往【设置】检查 API Key 是否准确无误；若使用海外模型服务（如 OpenAI/Claude），请确认系统代理端口已开启 TUN 模式或在配置中指定了有效的代理反向服务网关。

### Q2: 渲染出来的视频画面出现卡顿或音画不同步？
- **排查**：请确认导出的帧率与基准工程一致。在 Step 8 中重新点击“重新对齐音轨 (Audio Sync)”可按实际毫秒对白时长自动拉伸镜头持续时间。

### Q3: 导出的 4K 视频在某些播放器打开只有黑屏？
- **排查**：部分老旧播放器对 HEVC (H.265) 硬件解码支持有限。可于 Step 9 导出面板将编码格式切换为兼容性最高的 **H.264 (AVC) MP4** 格式导出。
